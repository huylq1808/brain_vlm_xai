# Brain imaging model landscape 

**Active priority revision — 2026-10-06:** MRI VLM + claim verification is the current project. Public frozen PRIMA has been run by the user on Colab; NeuroVFM is a conditional access-dependent comparator. The catalog below is literature context, not a mandatory download list or a controlled project leaderboard. Current states/data/steps are in [handoff](../../research_proposal/10_IMPLEMENTATION_HANDOFF.md) and [protocol 11](../../research_proposal/11_DATASET_TRAINING_EVALUATION_PROTOCOL.md). This update fixes execution alignment, not a fresh audit of every listed model release.

## How the models are ranked

The **priority rank** within each task uses four criteria, in this order:

1. **Direct evidence:** Was the model evaluated on the named dataset or a clearly identified version of it? Direct evidence outranks an architectural claim.
2. **Task and input match:** Does it accept the actual input (2D image, full CT/MRI volume, or multi-sequence study) and produce the required output (label, mask, answer, or report)?
3. **Reproducibility:** Are weights, code, and enough preprocessing details available? “Paper/code available” is weaker than released weights.
4. **Clinical robustness:** Is there external validation, lesion localization, expert review, or explicit hallucination/error analysis?

The ranks therefore mean **which model to test first for this project**, not a claim that one model beats every other model. Where published studies use different splits, I give no cross-paper performance ranking. Before any claim of SOTA, run candidates on the **same patient-level held-out set**, use the same input information, and report confidence intervals.

**Segmentation comparator, when that task is selected:** Consider [nnU-Net v2](https://github.com/MIC-DKFZ/nnUNet) as a task-trained reference. It is a separate comparison from explaining a fixed classifier. For ISLES'26, compare challenge results using the **same data/version and hidden evaluation**; [the organizer](https://isles-26.grand-challenge.org/dataset/) states that all 1,453 public cases are training data.

**Why Prima belongs near the top:** Unlike a generic 2D medical VLM, Prima was pretrained by aligning complete, multi-sequence brain MRI studies with radiology reports, and its published evaluation is prospective. The later [NeuroVFM study](https://www.nature.com/articles/s41591-026-04497-1) includes Prima as a comparator on its own diagnostic protocol and reports stronger average representations for NeuroVFM; that result does not erase Prima's value for report-aligned MRI retrieval or prove that NeuroVFM wins on MR-RATE or BIND. The [Prima paper](https://doi.org/10.1038/s41551-025-01608-0) and [released inference pipeline](https://github.com/MLNeurosurg/Prima) make it a practical candidate to test.

## Active comparator order — MRI first

1. Reproduce frozen PRIMA study/CLIP features on the same eligible development inputs; A/B checks preprocessing, coordinate provenance and paired-text behavior. NeuroVFM comparison waits for approved weights and compatible runtime/input scope.
2. Establish MRI report-generation and spatial baselines: AutoRG is a candidate with its own visual pipeline and dataset exposure; a PRIMA-conditioned AR decoder needs a trained/compatible connector. A pretrained language model alone does not understand MRI tokens.
3. Evaluate automatic grounding against compatible source masks/reviewed claim links. Compare predicted and oracle evidence separately. Only then test an image-aware verifier against text-only, protocol-rule and shuffled-image controls.
4. Compare selective correction with no editing and deterministic rendering at comparable useful finding recall/coverage. Diffusion/ItemizedCLIP and learned editors follow only if a measured gap motivates them.
5. Keep M10 attribution targets fixed and compare relevant/unrelated interventions; overlap is separate from image truth. Use a compatible independent clinical source only after access/pairing/exposure audit. 2D QA/caption and CT model lists above remain optional separate tasks.

No model is declared the project winner from published cross-cohort numbers. [Evaluation 06](../../research_proposal/06_EVALUATION_AND_EXPERIMENTS.md) defines endpoints/controls. Mask-only comparators are spatial references, not full VLM verification/reporting baselines.
